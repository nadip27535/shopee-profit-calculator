# Shopee Profit Calculator

Aplikasi web PWA untuk menghitung estimasi laba bersih, menyimpan produk dan transaksi, melihat laporan, serta ekspor CSV/backup JSON.

## Cara mencoba di komputer
Buka `index.html` di browser. Untuk fitur instalasi PWA dan offline, jalankan melalui hosting HTTPS atau server lokal.

## Cara memasang di iPhone
1. Upload seluruh isi folder ini ke hosting yang menyediakan HTTPS (misalnya GitHub Pages atau Netlify).
2. Buka alamat website tersebut melalui Safari.
3. Tekan Share > Add to Home Screen > Add.
4. Jalankan dari ikon di Home Screen.

## Catatan
- Data disimpan di localStorage browser/perangkat, bukan cloud. Backup berkala melalui menu Pengaturan.
- Untuk pindah perangkat, ekspor Backup JSON dari perangkat lama lalu impor di perangkat baru.
- Persentase biaya layanan perlu disesuaikan dengan rincian aktual pada Seller Centre. Aplikasi tidak terhubung resmi ke Shopee.
- Biaya layanan dihitung dari omzet kotor atau omzet setelah voucher sesuai pilihan. Biaya tetap dimasukkan sebagai nilai per pesanan.
