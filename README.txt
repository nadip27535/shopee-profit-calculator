Shopee Profit Calculator V2
1. Upload semua file ke GitHub Pages (replace file versi lama).
2. Buka website dan masuk menu Laporan.
3. Masukkan modal per item, pilih laporan Penghasilan .xlsx, tekan Baca & pratinjau.
4. Periksa jumlah item tiap pesanan, lalu impor.
5. Impor CSV iklan untuk mencatat biaya iklan total periode secara terpisah.

Catatan:
- Pembaca Excel memakai SheetJS CDN sehingga perlu internet saat memuat aplikasi/import.
- Data tetap disimpan lokal di browser/perangkat.
- Jumlah item pada laporan Penghasilan diperkirakan dari jumlah baris SKU per pesanan. Periksa jumlah item sebelum impor.
- Biaya iklan dari file rekap tidak dialokasikan otomatis per hari/pesanan.
- Ini belum integrasi API resmi Shopee; sinkronisasi API menunggu persetujuan dan kredensial Open Platform.
